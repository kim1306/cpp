Detailed Description

Represents a calendar date as day, month, and year.

Stores dates in the range 1/1/1900 to 31/12/9999. Month and day are validated against legal ranges. Leap year is accounted for in February day validation.

Input format (operator>>): DD MM YYYY e.g. 15 06 2024 Output format (operator<<): DD/MM/YYYY e.g. 15/06/2024
